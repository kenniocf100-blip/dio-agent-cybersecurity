# DIO Agent — Cybersecurity Analyst 🛡️

## 📌 Sobre o Projeto

Este projeto consiste na especialização do DIO Agent como um mentor de Cibersegurança, com foco em análise de vulnerabilidades, Application Security (AppSec) e Blue Team.

O objetivo é transformar o agente em um assistente capaz de analisar vulnerabilidades, identificar riscos, avaliar impactos e probabilidades, recomendar medidas corretivas e orientar a validação das correções.

## 🎯 Objetivos

- Desenvolver uma skill especializada em análise de vulnerabilidades.
- Ensinar conceitos fundamentais de Segurança da Informação.
- Identificar falhas de segurança em códigos.
- Avaliar impacto, probabilidade e severidade.
- Recomendar medidas de mitigação.
- Validar correções por meio de testes em laboratório.

## 🧩 Especialização Desenvolvida

**Skill: Vulnerability Analysis**

Foi criada uma skill para orientar o agente durante análises de segurança, seguindo um processo estruturado de identificação, avaliação e correção de vulnerabilidades.

### Arquivos desenvolvidos

- `skills/vulnerability-analysis/SKILL.md` — Instruções da skill.
- `skills/vulnerability-analysis/README.md` — Documentação da skill.
- `agent/knowledge/security-basics.md` — Fundamentos de Segurança da Informação.
- `agent/persona.md` — Personalidade e comportamento do agente.
- `AGENTS.md` — Registro e orientação de utilização da skill.

## 🔬 Laboratório Prático — SQL Injection

Foi desenvolvido um laboratório utilizando Python, Flask e SQLite para demonstrar uma vulnerabilidade de SQL Injection.

O laboratório possui:

- Código intencionalmente vulnerável.
- Código corrigido utilizando consultas parametrizadas.
- Testes automatizados com Pytest.
- Comparação entre o comportamento vulnerável e o corrigido.
